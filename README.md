# CasioLLM

Copias recuperables de los add-ins retirados de una Casio fx-CG50 durante el
experimento LLM. Este repositorio se ampliará posteriormente con el runtime,
el tokenizer y los artefactos de modelo que se decida publicar.

## Add-ins respaldados

- `add-ins/Casio/`: Geometry, Prob Sim, 3D Graph y Picture Plot.
- `add-ins/Games/`: Supermar.

Los binarios se preservan tal como estaban instalados en la calculadora.
